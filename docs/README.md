- `CONFIGURATION.md` — settings hierarchy, embed config, and API usage
- `DEVELOPMENT.md` — local setup, workflows, and feature patterns
- `DEPLOYMENT.md` — CI/CD paths, secrets/variables, and release steps
- `GIT_WORKFLOW.md` — branching model, versioning rules, and release PR steps
- `TESTING.md` — local test commands, CI jobs, and branch protection expectations
